1 项目概述
1.1 项目背景
本系统面向医院体重管理门诊、康复减脂机构、专业健康管理中心，打造一体化数字化体重管理临床工具，覆盖患者建档、全维度身体评估、生活习惯调研、肌力专项测评、个性化营养 + 运动处方生成、全周期数据管理、标准化报告输出完整业务链路。系统配套鹊动系列肌力测试设备，支持测评报告自动解析，基于循证医学标准自动生成适配减重人群的徒手、设备专项训练方案，实现云端多终端数据互通、患者干预全流程可追溯、数据可视化统计。
1.2 系统核心价值
全流程数字化闭环：患者建档→体格体成分评估→生活方式调研→肌力测评→智能减重方案生成→报告导出→周期复测迭代；
双体系标准化肌力测评：独立等速肌力、等张肌力测评板块，支持手动录入 + 官方 PDF 文件自动解析，区分左右侧单侧 / 双侧数据独立存储分析；
量化 + 定性双维度肌力诊断：系统自动完成分项百分打分、综合评级、专业文字解读，肌力短板自动识别并匹配对应训练动作；
训练方案动态迭代：留存患者全部历史测评数据，复测后自动对比肌力指标，智能调整训练强度、组数、负荷，同步推送周期复测提醒；
分层精细化数据管理：医生专属报告中心一站式管理名下全部患者数据，支持检索、预览、批量导出、减重趋势可视化图表；管理员拥有全平台数据总览、筛选、溯源管控权限；
精准隔离式方案匹配：专项设备训练方案仅在完成对应肌力测评后生成，通用徒手训练方案开放通用场景，杜绝方案错配、漏配；
标准化临床输出：全部评估、干预内容可一键生成完整 PDF 报告，符合《成人肥胖食养指南》《ACSM 运动处方指南》临床规范。
1.3 适用业务场景
医院内分泌 / 营养科体重管理门诊；
康复机构减脂、体态矫正、肌力恢复干预项目；
商业健康管理中心体脂管控、产后减重服务。

3 用户角色与权限管控
3.1 系统角色定义
管理员（admin）：平台系统运维账号，拥有系统全部功能、后台配置、全平台数据管控权限；
医生（doctor）：临床业务账号，仅负责自身名下患者建档、评估、方案、报告管理，无系统配置、全局数据查看权限。
3.2 完整权限矩阵
3.3 数据隔离规则
数据库行级安全策略（RLS）控制患者数据：每条患者数据绑定归属医生账号，医生仅能读写本人建档患者；
管理员可查询、查看平台全部医生及对应所有患者数据，但患者档案归属关系永久保留，不可篡改；
系统全局配置数据所有登录账号可读，仅管理员支持编辑保存；
肌力测评左右侧数据独立存储、独立解析、独立展示，不可混淆覆盖；
患者全周期数据（多轮测评、多版训练方案、问卷记录）绑定唯一患者 ID，全程可溯源，历史记录不可删除。
4 全系统功能模块需求
4.1 用户认证系统
4.1.1 登录功能
页面元素：鹊动 Logo、系统名称、用户名输入框、密码输入框、登录按钮、注册账号跳转入口、隐藏演示账号区域、回车快捷登录；
前端基础校验：账号、密码不可为空；
数据库校验逻辑：校验用户名是否存在、密码匹配、账号状态（正常 / 冻结）；
登录成功流程：更新云端账号最后登录时间、写入本地会话缓存、根据角色自动跳转对应首页、加载该账号名下全部患者云端数据；
差异化错误提示：用户名不存在、密码错误、账号已冻结、网络连接失败；
会话控制：默认 60 分钟无操作自动清除会话并跳转登录页；手动退出登录清空本地会话缓存。
4.1.2 账号注册功能
表单字段：真实姓名、用户名（字母数字，最少 3 位）、登录密码（最少 6 位）、确认密码、联系手机号（选填）；
前端校验：用户名长度、密码长度、两次密码一致；
数据库校验：检测用户名是否已被占用；
账号创建规则：新建账号默认角色为 doctor、状态正常；注册完成自动登录跳转患者登记页面。
4.1.3 全局主题切换
顶部导航栏内置亮色 / 暗色切换按钮；
主题配置存储至 localStorage 固定 key；
通过 HTML 标签 data-theme 属性联动 CSS 变量切换页面样式。
4.2 患者首诊登记模块
4.2.1 基础信息采集
必填项：患者姓名、性别、出生日期（系统自动计算年龄）；
选填项：联系电话、职业、工作体力等级（久坐 / 轻度 / 中度 / 重度体力）。
4.2.2 减重目标信息
减重主要原因、过往减重经历、是否反弹、目标体重、期望减重周期（3/6/12 个月 / 不限）。
4.2.3 病史与用药信息
既往病史多选：高血压、糖尿病、高脂血症、甲状腺疾病、多囊卵巢、心血管、骨关节、睡眠呼吸暂停、心理疾病；新增【无】可选选项；
药物 / 食物过敏、当前长期服药记录文本录入框。
4.2.4 生活基线数据
日均饮水量、含糖饮料摄入频率、每日睡眠时长、睡眠质量、日常压力等级。
4.2.5 运动基线数据
现有运动频率、单次运动时长、运动类型多选、膝腰不适情况、运动意愿强弱。
4.2.6 饮食基线数据
每日进餐次数、是否吃早餐、主食类型、蔬菜日均摄入量、烹饪方式、外卖外食频率。
4.2.7 交互逻辑
一键填充演示测试数据；
工作性质选择联动综合评估页面活动系数；
表单数据本地缓存，点击保存同步写入云端数据库；
保存完成可直接跳转综合评估页面。
4.3 综合评估模块
4.3.1 体格测量录入与自动计算
必填：身高、体重（系统自动计算 BMI 并输出分级：偏瘦 / 正常 / 超重 / 肥胖 / 重度肥胖）、静息心率；
选填：腰围、臀围（自动计算腰臀比，按男女区分风险等级）、颈围、收缩压 / 舒张压。
4.3.2 体成分数据录入
体脂率、骨骼肌量、体脂肪重量、内脏脂肪等级、实测基础代谢、InBody 身体评分。
4.3.3 能量代谢自动计算模块
活动水平下拉选择，匹配对应活动系数；
减重阶段选择：温和 / 标准 / 强化减重，自动匹配热量缺口；
系统自动运算：BMR（Mifflin-St Jeor 公式）、TDEE 每日总消耗、每日目标摄入热量；
热量安全限制：男性最低 1200kcal，女性最低 1000kcal，目标热量不得低于基础代谢；
自动计算每周预期减重公斤数。
4.3.4 运动风险自动判定
PAR-Q 问卷结果、心血管风险等级、运动禁忌项，综合输出整体运动风险（低 / 中 / 高）。
4.3.5 新增：生活习惯专项调研问卷
调研维度：日常饮食结构、作息规律、每日久坐时长、饮水习惯、不良体态、熬夜频率；
联动规则：问卷数据结合体格、肌力测评结果，在综合评估报告中自动生成个性化生活方式整改干预建议。
4.4 智能营养与运动方案生成模块
4.4.1 个性化饮食方案
自动计算宏量营养素：蛋白质（1.2g/kg 体重）、脂肪、碳水每日克数与供能占比；约束膳食纤维、食盐、添加糖、每日饮水标准；
三餐热量分配 3:4:3，拆分每餐碳水、蛋白、脂肪克数；
标准化进餐行为指导、进餐顺序规范；
食物红绿灯分类表（主食 / 蛋白 / 蔬菜 / 水果 / 脂肪 / 饮品，绿灯鼓励、黄灯适量、红灯限制）；
营养素三色可视化比例图表展示。
4.4.2 有氧训练方案（FITT-VP 三阶段）
分适应期、强化期、巩固期配置训练频率、时长、运动强度、RPE 疲劳度、周总运动时长；
Karvonen 公式自动计算目标心率区间；
完整训练流程：热身 5-10min→主体训练→放松拉伸；
护膝护腰运动优先级排序：快走 > 椭圆机 > 游泳 > 骑行 > 慢跑 > 划船机。
4.4.3 基础抗阻、柔韧性训练方案
抗阻训练分阶段配置频率、强度、次数、组数、休息时长，内置 7 套标准基础动作；
柔韧性训练：每周 2-3 次，静态拉伸 15-30 分钟，固定 9 组拉伸动作序列；
自动生成 7 天完整周训练日程表，区分有氧、抗阻、休息、拉伸安排。
4.4.4 方案编辑与重新生成
所有方案卡片支持在线编辑修改，一键基于最新评估数据重新生成全套方案。
4.4.5 肌力训练方案匹配规则
系统区分两类训练方案，匹配逻辑强制生效：
徒手训练方案：完成任意一类肌力测评（等速 / 等张）即可自动生成，通用减脂基础肌力训练；
鹊动设备专项方案
录入 / 上传等速肌力数据 → 仅生成等速设备专项训练方案，无数据则隐藏并提示；
录入 / 上传等张肌力数据 → 仅生成等张设备专项训练方案，无数据则隐藏并提示；
方案动态迭代逻辑
永久保存患者所有历史肌力测评记录；
新复测完成后自动对比肌力指标，判定肌力提升 / 持平 / 下降；
自动进阶、维持或降低训练负荷、组数、次数、训练周期；
系统计算训练周期，在医生报告中心、患者档案推送复测提醒。
4.5 肌力评估模块（等速肌力、等张肌力双独立板块）
4.5.1 通用基础规则
两大板块页面完全独立、逻辑隔离；均支持两种数据录入方式：手动填写指标、上传官方 PDF 报告自动解析；
上传文件前置强制校验：必须选择测评设备、测试肢体侧别；等速补充测试速度，等张补充测试重量，参数不全禁止解析；
报告分两类：双侧综合报告（仅需上传 1 份，系统自动拆分左右）、单侧独立报告（左右需分别上传两份）；
PDF 解析容错：区分文件损坏、非鹊动官方报告、格式不兼容三类场景，精准弹窗提示；
所有设备报告上传为非必填项，上传数据越完整，评估打分、方案匹配精准度越高。
4.5.2 等速肌力评估板块
适配鹊动 01/02/05/06/07/08/09 七款设备；
手动录入字段：基础信息、向心 / 离心峰值力矩 PT、PT/BW、总功、平均功率、疲劳指数 FI、H/Q 比值、肢体对称指数 LSI；
PDF 解析功能：自动抓取测试速度、左右侧力矩、疲劳指数、平衡比值等核心指标回填表单；
自动计算 LSI、PT/BW 等衍生指标。
4.5.3 等张肌力评估板块
手动录入核心指标：1RM、XRM、重复训练次数、负荷重量；
支持等张设备官方 PDF 报告上传解析回填表单。
4.5.4 标准化肌力评估输出体系（等速 / 等张通用）
定性文字解读：肌力整体水平、薄弱肌群定位、关节运动损伤风险、肢体功能受限分析；
定量百分制打分：五大维度分项打分（肌力均衡度、肌力等级、双侧差值、肌肉耐力、肢体运动功能），生成综合总分；
五级综合评级：优秀、良好、一般、薄弱、异常，搭配环形得分图表可视化展示。
4.5.5 肌力诊断与方案匹配
系统自动识别薄弱肌群、肌力短板，匹配对应鹊动设备训练项目；
分别输出：减脂徒手肌力训练方案、鹊动设备专项训练方案，包含动作、组数、次数、间歇、训练周期、安全提示。
4.6 报告导出与打印模块
4.6.1 完整报告固定结构
封面→患者基础信息→体格与体成分评估→能量代谢计算→个性化饮食方案→有氧训练方案→抗阻训练→柔韧性训练→周训练日程→食物红绿灯→减重复评计划→肌力评估板块（有数据则展示，无数据隐藏）→医师签名区→页脚临床依据标注。
4.6.2 肌力板块差异化展示
仅录入等速数据则展示等速评估；仅录入等张数据则展示等张评估；两类数据均存在则分板块并列展示；报告包含肌力打分表、评级、历史复测对比、生活干预建议。
4.6.3 打印与 PDF 导出规范
调用浏览器原生打印接口生成 PDF；
CSS 打印专用样式，页面操作按钮设置 no-print，打印自动隐藏；
图片加载失败自动隐藏，避免打印空白占位；
报告内置固定配图：系统 Logo、营养 / 有氧 / 抗阻 / 拉伸插图、设备实拍图、吉祥物横幅。
4.7 医生工作台 - 报告中心（独立页面）
数据聚合：单页面汇总当前医生名下所有患者全周期档案，包含登记记录、综合评估、肌力测评报告、训练方案；
数据归类：按日期自动分组展示当日新增业务记录；
检索筛选：支持自定义时间区间、患者姓名精准搜索；
操作功能：报告在线预览、历史数据回溯、批量导出患者完整 JSON 档案；
可视化统计：自动生成数据汇总报表、患者减重趋势折线图、肌力变化对比图表。
4.8 系统管理后台（仅管理员访问）
4.8.1 基础后台功能
统计概览卡片：活跃医生数量、管理员账号总数、全平台总账号、数据库存储类型；
账号管理列表：展示用户名、姓名、角色、账号状态、创建时间、最后登录时间；支持新增账号、冻结 / 解冻、重置密码、删除账号；危险操作全部增加二次确认弹窗；
全局系统配置：机构名称、系统标题、默认减重阶段、默认活动水平、密码最小长度、会话超时时间；支持保存配置、一键恢复系统默认参数；
本地缓存管理：一键清空浏览器本地 wm 前缀缓存，云端数据不受影响。
4.8.2 全局数据管理（管理员专属新增模块）
查看平台全部医生账号及各自名下所有患者完整数据；
多维度筛选检索：医生姓名、测评时间段、患者姓名；
全平台数据自动汇总统计、异常测评记录溯源、批量导出全平台备份数据。
5 数据库整体设计

6 数据安全与隐私规范
6.1 现有安全管控机制
数据库 RLS 行级隔离，限制跨账号访问患者档案；
会话超时自动登出，防止账号长期挂起泄露数据；
账号冻结机制，违规账号禁止登录；
密码长度最低限制，提升基础账号安全。
6.2 待落地安全优化项
高风险：用户密码明文存储，需改造为 bcrypt/argon2 哈希加密；
中风险：前端硬编码数据库密钥，需搭建后端代理中转 API 请求；系统无强制 HTTPS 跳转；
低风险：缺少操作审计日志、无用户自助修改密码页面。
6.3 患者隐私约束规范
肌力左右侧数据独立存储，不可随意篡改覆盖；
患者历史测评、训练记录仅支持新增复测，不提供删除功能，保证数据完整溯源；
批量导出全量患者数据、重置账号、删除账号等高风险操作必须弹出二次确认弹窗。

9 附录：计算公式、常量、评分标准
9.1 代谢减重计算公式
Mifflin-St Jeor BMR
男性：BMR = 10 × 体重 (kg) + 6.25 × 身高 (cm) - 5 × 年龄 + 5
女性：BMR = 10 × 体重 (kg) + 6.25 × 身高 (cm) - 5 × 年龄 - 161
TDEE = BMR × 活动系数（1.2/1.375/1.55/1.725/1.9）
每日目标热量 = TDEE - 热量缺口，遵循男女最低热量安全底线
每周减重速度 =（7 天总热量缺口）÷ 7700（7700 大卡≈1kg 脂肪）
Karvonen 目标心率：HRmax=220 - 年龄；HRR=HRmax - 静息心率；目标心率区间 = HRR× 强度 %+ 静息心率
宏量营养素分配公式：蛋白质 1.2g/kg 体重；脂肪按总热量 25% 计算；碳水填充剩余热量
9.2 肌力评估分级常量
PT/BW 分级：男≥2.0 优秀、≥1.5 良好、≥1.0 一般、＜0.8 较差；女≥1.5 优秀、≥1.2 良好、≥0.9 一般、＜0.7 较差
疲劳指数 FI：≤50 正常、50-60 需关注、≥60 耐力显著下降
H/Q 比值：60-80 理想，＜60 腘绳肌薄弱高损伤风险
LSI 肢体对称差值：＜15% 正常、15%-20% 轻度失衡、≥20% 显著失衡
9.3 肌力综合评分规则
基础分 70 分；
加分项：PT/BW 优秀 + 15、良好 + 10；FI 正常 + 5；H/Q 理想 + 10；LSI 正常 + 5；
减分项：PT/BW 较差 - 15；FI 耐力差 - 10；H/Q 偏低 - 15；LSI 显著失衡 - 10；
总分 0-100，对应五级评级标准。
9.4 训练标准常量
有氧三阶段 FITT-VP 全套周期、频率、时长、强度参数；
抗阻训练分阶段组数、次数、间歇时长；
鹊动 9 台设备对应肌群、运动轨迹；
柔韧性标准 9 组拉伸动作序列。
10 系统整体验收标准
